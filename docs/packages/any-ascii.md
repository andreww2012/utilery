# Package: [`any-ascii`](https://npmx.dev/any-ascii)

> **Legend:** ✅ added · ❌ not added (see notes) · 🚧 under consideration · ⌛ planned

Transliterates any Unicode text into ASCII.
Its data table is large (about 550 kB), so it only ends up in a bundle that uses `string/slugify`.
